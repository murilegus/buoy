# Design

How Buoy looks: sizes, spacing, radii, type and colour, one page per part (the pill, the
compact, alerts and asks, expanded, Home, tabs, icons, Bu, motion), with one table of numbers and one
colour palette. The SPEC says what Buoy does and when; these pages say what it looks like.

Design pages are written and decided in Vietnamese first; the English pages follow. Until then
they are in Vietnamese only: switch the site's language to **Tiếng Việt**, or read them on
GitHub in [docs/design](https://github.com/murilegus/buoy/tree/main/docs/design) (`*.vi.md`).

The decisions there are the v0.2 redesign (FEATURES, M4); the code and the SPEC describe v0.1
until those items land.
