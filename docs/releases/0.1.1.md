A small update to Buoy 0.1, made while preparing it for extensions.gnome.org.

## Fixed

- **Files are read in the background.** App profiles, Claude Desktop's session files, the
  Fn Lock light and the parent of a Claude Code hook are now read without making GNOME Shell
  wait, however briefly.
- **Settings clean up after themselves.** Closing Buoy's settings right after opening them no
  longer leaves a pending task behind.
- **Clipboard use is stated.** The extension's description now says what Buoy reads when you
  copy something, and how to turn that off.

Two downloads, the same extension: `buoy@murilegus.shell-extension.zip` (what `install.sh`
uses) and `buoy@murilegus-v0.1.1.shell-extension.zip` (the version in the name).

Update with `curl -fsSL https://murilegus.dev/buoy/install.sh | bash -s -- --update`, then log
out and back in.
