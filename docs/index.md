# Buoy

A GNOME Shell 50 extension: a Dynamic-Island-style living pill in the top bar.

- **Design** — how Buoy looks: sizes, spacing, type, colour, one page per part. Written and
  decided in Vietnamese first; the English pages follow.
- **Product** — what Buoy does: the spec, the roadmap, the order of the pills, the lights,
  notifications, the greeting and Bu.
- **Build on Buoy** — the architecture, the activity contract, the D-Bus interface, app
  profiles and the coding agents.

To install and use Buoy, see the [README](https://github.com/murilegus/buoy#readme).
